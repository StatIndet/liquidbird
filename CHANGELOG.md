# Changelog

All notable changes to LiquidBird are documented in this file. LiquidBird follows
[Semantic Versioning](https://semver.org/) for its public releases.

## Unreleased

### Changed

- Nothing yet.

## 0.1.0 - 2026-07-25

### Added

- Initial public preview of the LiquidBird macOS 27 theme for Thunderbird.
- Styling for mail, compose, address book, calendar, tasks, chat, settings,
  account settings, add-ons, menus, panels, and dialogs.
- Adaptive light and dark appearances, system accent integration, density
  support, increased-contrast behavior, and reduced-motion/transparency
  fallbacks.
- A freely redistributable Lucide icon set and complete third-party notices.
- Safe installation, update, rollback, and troubleshooting documentation.
- Automated repository validation and deterministic release packaging.
