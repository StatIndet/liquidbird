# Community code of conduct

LiquidBird should be a welcoming, constructive project for contributors and
users of every background and experience level.

## Expected behavior

- Be respectful, patient, and specific.
- Critique code and design decisions, not people.
- Assume good intent while remaining open to correction.
- Protect other people's privacy, especially in screenshots and diagnostics.
- Accept maintainers' decisions about project scope and release safety.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized conduct, personal attacks,
doxxing, deliberate disruption, and publishing another person's private
information are not tolerated in project spaces.

## Enforcement

Report conduct concerns privately to the project maintainers through the
repository owner's public contact channel. Maintainers may edit or remove
content, close or lock conversations, reject contributions, or temporarily or
permanently restrict participation when necessary. Reports will be handled as
confidentially as practical, with conflicts of interest disclosed and avoided.

This code applies in repository discussions and in other public spaces when a
person is representing LiquidBird.
