# LiquidBird support

LiquidBird is an independent community theme built on Thunderbird's unsupported
`userChrome.css` and `userContent.css` customization mechanisms. Thunderbird
updates can rename or restructure internal components without notice.

## Supported configuration

macOS is the supported platform. See the
[compatibility matrix](docs/COMPATIBILITY.md) for the exact versions and
configurations that have been verified. Other Thunderbird versions and other
operating systems are best-effort only.

## Getting help

Before reporting a problem:

1. Follow the [troubleshooting steps](README.md#troubleshooting).
2. Confirm that the problem disappears when LiquidBird is disabled.
3. Confirm that it remains when other custom CSS and add-ons are disabled.
4. Search existing issues.

When filing a visual bug, use the repository's bug-report form. Screenshots
must not expose personal addresses, message content, account names, or profile
paths.

## Scope

Support covers reproducible LiquidBird styling defects on a verified
configuration. General Thunderbird problems, add-on compatibility, custom CSS,
and unsupported platforms may receive community help but are not guaranteed.
